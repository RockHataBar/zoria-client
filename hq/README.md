# Штаб "Зорі"

Показ - другий вхід застосунку. Відкривається без мережі: на прийманні, на
трансляції і локально під драйвером. Дані подає господар показу.

## Що вміє

- **Долина**: мапа голок і машин за правдою світу, за вірою фокуса або обидва
  шари разом; розбіжності, мовчання і пам'ять про чужі машини видно на мапі.
- **Перемотування**: будь-який такт будь-якої партії, вперед і назад,
  рахунок і голки фокуса на такті.
- **Канал**: байти, команди і відмови фокуса за тактами, причина відмови
  кожної команди, пік відмов у партії.
- **Пресети**: порівняння `preset-a` і `preset-b` за статтями рахунку і
  переведення пресета в бій.
- **Ефір**: показ іде за стелею без відставання, наприкінці - частки партії.

Правду світу рахує рушій у воркері; основний потік тільки малює.

## Збірка і перевірка

```sh
npm ci
npm run build                         # dist/index.html, один самодостатній файл
npx zaria-kit records                 # еталонний запис і пара пресетів
npx zaria-kit hq-check --seed 4242    # драйвер приймання
```

## Де що лежить

| Файл | Що в ньому |
|---|---|
| `src/index.html` | розмітка: якорі значень і органи керування |
| `src/hq.js` | основний потік: подача господаря, органи, якорі, малювання |
| `src/worker.js` | воркер: черга запитів, прогрів курсорів, ефір |
| `src/core.js` | партія: курсор рушія, щоденник віри, кадри і відмови каналу |
| `src/map.js` | мапа долини і стрічка каналу |
| `src/guest.js` | обгортка господаря показу - копія з кита |
| `src/strings.js` | рядки українською та англійською |
| `vite.config.js` | збірка в один `index.html` |
